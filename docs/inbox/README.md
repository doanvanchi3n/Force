# Ghi chú chưa phân loại

Obsidian lưu ghi chú mới vào thư mục này. Chuyển ghi chú có nội dung sang thư mục
phù hợp sau khi đặt tên rõ ràng.

Các tệp `Chưa đặt tên*.base`, `Chưa đặt tên.canvas` và ghi chú `2026-11-06.md`
được giữ lại từ vault cũ. Chúng chưa có nội dung đủ để phân loại; không bị xóa trong lần sắp xếp này.
